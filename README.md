# INKCRAFT — сайт

Статический сайт: `index.html`, `styles.css`, `script.js`. Сборка не нужна — загрузить папку на любой хостинг.

## Фотографии
Положите реальные фото в `images/` под этими именами (формат WebP, качество ~70–80%).
Пока файла нет, на его месте показывается аккуратная заглушка.

| Файл | Где | Размер |
|---|---|---|
| hero.webp / hero-mobile.webp | Первый экран | 1920×1280 / 900×1600 |
| service-bathroom / -kitchen / -partial / -turnkey.webp | Услуги | 800×600 |
| case1..3-before / -process / -after.webp | До / после | 1200×900 |
| work-bath-1..3, work-kitchen-1..3, work-flat-1..3.webp | Галерея (work-bath-1, work-flat-2, work-kitchen-3 — вертикальные 800×1000) | 800×600 |
| og.jpg | Превью ссылки в мессенджерах | 1200×630 |

Больше фото в галерее — скопировать `<li data-cat="bath|kitchen|flat">`.

## Что заполнить
- **До / после**: подписи объектов («Район — указать») → реальный тип и район.
- **Facebook / Instagram** (footer): вставить ссылки в `href`. Пока ссылка `#`, пункт скрыт.
- **Отзывы**: раскомментировать шаблон `.review` в `index.html`. Блок появляется сам, когда есть хотя бы один отзыв.
- **Домен**: раскомментировать `<link rel="canonical">`, при желании добавить sitemap.xml.
